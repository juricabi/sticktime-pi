# Test vectors for the sticktime.txt format, shared by host/tests/test_settings.c (settings.c) and
# image/tests/test_settings_py.py (settings.py): both must give exactly these results.
#
# Lines are "<directive>: <payload>" (the space after the colon is optional); '#' lines and blank lines
# are ignored. Payloads use escapes: \\ \n \r \t \0 \s (a space; write leading/trailing spaces this
# way) and \xHH (a byte). Anything else is literal, including UTF-8. A KEY is the first word of the
# payload (escapes allowed), then " = VALUE" (" =" alone is an empty value).
#
#   case: NAME              starts a case: a fresh parse of the "in" text
#   in: TEXT                the file content (in lines join without separators)
#   inrep: N TEXT           TEXT repeated N times, appended to the content
#   warn: TEXT              one expected warning line. A run of warn lines is the complete list at that
#                           point. Right after the parse, no warn run means "no warnings".
#   nowarn:                 no warnings at this point
#   raw: KEY = VALUE        settings_raw(KEY) == VALUE;  "raw: KEY" alone: not set (NULL / None)
#   rawlen: KEY = N         the raw value is N bytes long
#   get: KEY = VALUE        settings_get(KEY) == VALUE (the effective value)
#   int: KEY DEF MIN MAX = N        settings_get_int
#   num: KEY DEF MIN MAX = X        settings_get_num (within 1e-9)
#   bool: KEY DEF = 0|1             settings_get_bool
#   each: KEY = VALUE       a run of each lines is the complete settings_each() list, in order
#   noeach:                 settings_each() gives nothing
#   set: KEY = VALUE        settings_set returns true;  set!: ... returns false
#   del: KEY                settings_set(KEY, NULL)
#   out: TEXT / outrep: N TEXT     a run of these is the exact serialization at that point
#   valid: KEY = VALUE      settings_validate gives no message;  invalid: ... gives one
#
# After every case the runners also check: serializing, parsing that again and serializing once more
# gives the same text, the same settings_each() list and the same warnings (but "NUL bytes removed");
# and a case without set/del serializes back to exactly its input (NUL bytes dropped).
