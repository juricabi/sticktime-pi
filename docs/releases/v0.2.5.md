## What's new

- **A sharper, flicker-free picture in goggles.** The AV output is now **progressive** (240p / 288p) by
  default: thin lines and text no longer flicker as they do on interlaced 480i / 576i. And the new
  `av_detail = high` (the default) draws the game with twice the lines (NTSC 4:3: 640x480 instead of
  320x240) and lets the Pi's display hardware scale it down: sharper text, smoother edges of gates and trees,
  for a few ms more work per frame (a Pi 4 keeps a steady 60 fps). `av_detail = normal` draws 240p / 288p as
  before. A card from before 0.2.5 keeps its `av_mode = interlaced`: to try progressive, web page → Video →
  Composite lines → Progressive (the app restarts; no reboot).
- **Tracks page**: a track in StickTime 1.8.0's bigger format (format 2: up to 48 gates and 64 structures,
  e.g. from the gallery) no longer shows as "the game can't read it" under **On the Pi**. The game read it
  all along; only the page checked for the older format. The Pi's guard for track slots knows format 2 now
  too: a big track the game has listed is kept as it was loaded if its file goes bad or away mid-game (as
  format 1 tracks always were), instead of reaching the game unchecked.
- **Status page: power warnings work again.** On today's Raspberry Pi OS (kernel 6.12) the page couldn't
  read the Pi's under-voltage and throttling flags, so a weak power supply went unnoticed. It now asks the
  firmware directly, as `vcgencmd get_throttled` does.
- The web server and the game's saves no longer run on the game's own CPU core only (they got what the game
  left over there): they use the other cores now, so the web page answers faster while you fly.
- The log's start line names the render size once (it said it twice).

## Update from the web page

From 0.2.1 or newer: Updates → Check → install StickTime Pi 0.2.5. The game stays at StickTime 1.9.0.

From 0.1.0 or 0.2.0: those updaters can't install updates (see the 0.2.1 notes): flash this image once.
Copy `sticktime.txt`, `sticktime/music` and, from `sticktime/sd/SCRIPTS/TOOLS`, `StickTime.dat`,
`StickTimeBW.dat`, `StickTimeLite/data.txt`, `StickTimeTracks` and `StickTimeGhosts` to your PC first, and
put them back after flashing (the WiFi password isn't in `sticktime.txt` any more after a boot: type it
again).
