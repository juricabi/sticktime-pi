## What's new

- **StickTime 1.10.0's tracks with scenery.** The game's new tracks have props, rails and decals (format 3, and
  format 4 for bigger ones). The **Tracks** page lists them under **On the Pi** when the game on the Pi is 1.10.0
  or newer; with an older game it says "the game can't read it", as that game doesn't list them. The Pi's guard
  for track slots knows them too: it reads them as the game does (format 4 up to 10000 bytes, structure kinds
  1-9, the scenery after the structures left to the game's own checks), hides one the game would crash on, and
  keeps a listed one as it was loaded if its file goes bad or away mid-game, all of it (a big track's last good
  copy was cut at 6000 bytes before).
- **The Tracks page follows the game the Pi runs:** with StickTime BW it lists the formats BW reads (1, and 3 from
  1.10.0 on), with the Lite none (it has no custom tracks).
- **Game updates with bigger gallery tracks.** The game's track gallery may now hold a track of up to 10000
  characters (format 4); before, one over 6000 made the Pi keep its old gallery.
- The track editor on the page is the game's own: after the game update it places props, rails and decals.

## Update from the web page

From 0.2.1 or newer: Updates → Check → install StickTime Pi 0.2.11, then StickTime 1.10.1 (in that order: an
older StickTime Pi runs it too, but lists its tracks with scenery as unreadable). Your settings, saves and
tracks stay as they are. A new image comes with StickTime 1.10.1.

From 0.1.0 or 0.2.0: those updaters can't install updates (see the 0.2.1 notes): flash this image once.
Copy `sticktime.txt`, `sticktime/music` and, from `sticktime/sd/SCRIPTS/TOOLS`, `StickTime.dat`,
`StickTimeBW.dat`, `StickTimeLite/data.txt`, `StickTimeTracks` and `StickTimeGhosts` to your PC first, and
put them back after flashing (the WiFi password isn't in `sticktime.txt` any more after a boot: type it
again).
