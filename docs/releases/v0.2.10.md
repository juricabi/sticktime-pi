## What's new

- **Release the WiFi module for the PC.** Status → Inputs → **Release module** asks the module to stop streaming
  to the Pi (`joystick_end`). An ELRS module then broadcasts again, so the PC app finds it by itself (ELRS /
  Crossfire WiFi Joystick for Windows 3.4 or for Linux 1.1.0, or any other app). The Pi stops listening until you
  press **Connect**, or until StickTime Pi starts again (a restart of the game, an update, a reboot). The page says
  what the module answered.
- **Shutdown and reboot release it too.** Before StickTime Pi exits (shutdown or reboot from the web page, an app
  update, the service stopping) it releases the module, waiting for its answer 1.5 s at most. Unplugging the Pi
  sends nothing: an ELRS module then streams on until its WiFi is switched off and on.
- Before, nothing ever stopped the module's stream, and an ELRS module that streams never broadcasts: the PC app
  could take it over only with its IP address set.
- Crossfire is not sent the stop: it broadcasts while it streams, so the PC app finds it anyway.
- The same WiFi joystick code as the Linux app 1.1.0, and the Windows app 3.4 follows the same rules (R14 in
  all three).

## Update from the web page

From 0.2.1 or newer: Updates → Check → install StickTime Pi 0.2.10. The game stays at StickTime 1.9.0. Your
settings stay as they are.
